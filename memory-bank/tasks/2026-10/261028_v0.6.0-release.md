# 261028_v0.6.0-release

## Objective
Cut v0.6.0: ship the opt-in automatic install feature (merged in PR #20), repair the six pre-existing backend test failures that blocked a green suite, correct the eleven stale locale hints, and move all five version manifests in lockstep.

## Outcome
- ✅ Version bumped 0.5.1 → 0.6.0 across `package.json`, `package-lock.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, and `src-tauri/Cargo.lock` via `scripts/bump-version.mjs`.
- ✅ Release notes created at `docs/release-notes/0.6.0.md` (required by `release.yml`, which refuses to tag without it).
- ✅ Memory bank updated (`activeContext.md`, `progress.md`, `decisions.md`, monthly README).
- ✅ Release branch `release/v0.6.0` → PR → `main`; merging triggers tag `v0.6.0` + draft release + Linux/Windows bundles.

## Files Modified
- `package.json`, `package-lock.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock` — version 0.6.0.
- `docs/release-notes/0.6.0.md` — highlights, changes, and the outstanding conditions.
- `memory-bank/activeContext.md`, `memory-bank/progress.md`, `memory-bank/decisions.md`, `memory-bank/tasks/2026-10/README.md` — state.

## Patterns Applied
- Release branch workflow: `release/vX.Y.Z` → PR → `main`, then `release.yml` tags and drafts the release.
- Version bumps go through `scripts/bump-version.mjs`, never hand-edited, so the five manifests cannot drift.

## Integration Points
- PR #20 (`feat(updater)`) delivered the feature; this PR only cuts the version.
- `release.yml` validates `package.json` against the tag and requires `docs/release-notes/0.6.0.md` on `main`.

## Open Conditions
- Manual smoke test of the auto-install path on a signed build.
- Native review of the eleven corrected `updates.autoInstallHint` strings.

## Corrections
- v0.5.0 bumped only `package.json`, so its installers reported 0.4.3 while the tag said v0.5.0. v0.5.1 repaired the drift; this release keeps all five manifests in lockstep.
- v0.5.1's notes claimed `antigravity-md` support, but the format registration landed in v0.6.0. Noted in `decisions.md` and in the 0.6.0 release notes.
