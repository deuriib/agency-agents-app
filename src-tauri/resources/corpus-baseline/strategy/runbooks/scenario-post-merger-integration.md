# Runbook: Post-Merger Integration

Mode: NEXUS-Full | Duration: 3-6 months | Agents: 22-30

## Scenario

You are integrating systems, data, brands, and teams after an acquisition. Customers must stay supported, compliance must remain intact, and the two organizations must become one without a freeze on delivery. The integration has to produce synergy without breaking either side's operations.

## Execution Plan

### Phase 1: Integration Baseline (Month 1)

```text
Week 1-2: Inventory Both Sides
├── Project Shepherd → Integration management office setup
├── Backend Architect → System and integration inventory
├── Data Engineer → Data asset inventory
├── Legal Compliance Checker → Contract and regulatory constraints
├── Finance Tracker → Synergy baseline
└── Quality Gate: Integration baseline approved

Week 3-4: Integration Plan
├── Senior Project Manager → Phased integration plan
├── Brand Guardian → Brand transition options
├── UX Researcher → Customer and employee research
├── Workflow Optimizer → Process harmonization map
└── Quality Gate: Integration plan approved by steering committee
```

### Phase 2: Systems & Data Convergence (Month 2)

```text
├── Backend Architect → Integration APIs and event backbone
├── Data Engineer → Customer and product data consolidation
├── Database Optimizer → Schema convergence
├── DevOps Automator → Unified CI/CD
├── SRE → Cross-estate observability
├── API Tester → Integration contract tests
├── Evidence Collector → QA on every integration change
└── Quality Gate: Core systems integrated in staging
```

### Phase 3: Brand & Customer Migration (Month 3)

```text
├── Brand Guardian → Brand transition rollout
├── UX Architect → Unified experience foundation
├── UI Designer → Unified customer surfaces
├── Content Creator → Customer migration communications
├── Support Responder → Support continuity and escalation
├── Social Media Strategist → External narrative
└── Quality Gate: Customer migration readiness review
```

### Phase 4: Process Unification (Month 4)

```text
├── Workflow Optimizer → Harmonized processes
├── Experiment Tracker → Process-change experiments
├── Analytics Reporter → Synergy and adoption tracking
├── Legal Compliance Checker → Post-integration compliance check
├── Reality Checker → Integrated-system quality verdict
└── Quality Gate: Process unification accepted
```

### Phase 5: Stabilization & Synergy Realization (Month 5-6)

```text
├── SRE → Stability and incident review
├── DevOps Automator → Decommission redundant tooling
├── Finance Tracker → Synergy realization report
├── Executive Summary Generator → Integration close-out
├── Project Shepherd → Lessons learned and handover
└── Quality Gate: Integration closed and synergies verified
```

## Key Decisions

| Decision Point | When | Who Decides |
| --- | --- | --- |
| Brand transition model | End of Month 1 | Brand Guardian + Executive Sponsor |
| Integration sequence | End of Month 1 | Project Shepherd + Backend Architect |
| Customer migration timing | Month 3 | Support Responder + Brand Guardian |
| Integration readiness | Month 4 | Reality Checker |
| Synergy sign-off | End of Month 6 | Finance Tracker + Executive Sponsor |

## Success Criteria

| Metric | Target |
| --- | --- |
| Customer support continuity | No gap in support coverage |
| Core systems integrated | By end of Month 2 |
| Customer migration completed | By end of Month 3 |
| Compliance review passed | Zero critical findings |
| Synergy target realized | ≥ 80% of committed value |
| Integration quality gates passed | 100% |

## Common Pitfalls & Mitigations

| Pitfall | Mitigation |
| --- | --- |
| Integration treated as IT-only | Project Shepherd coordinates brand, people, and process from Month 1 |
| Customer communications delayed | Content Creator and Support Responder staffed in Phase 1 |
| Synergy assumed rather than tracked | Finance Tracker establishes baseline and tracks monthly |
| Brand transition rushed | Brand Guardian presents options in Month 1, rollout in Month 3 |
| Redundant tooling left running | DevOps Automator owns decommission in Phase 5 |
