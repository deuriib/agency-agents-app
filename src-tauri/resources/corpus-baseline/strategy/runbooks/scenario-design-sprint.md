# Runbook: One-Week Design Sprint
>
> **Mode**: NEXUS-Micro | **Duration**: 5 days | **Agents**: 10-14

## Scenario

You have one week to answer a product question with evidence. The sprint compresses research, sketching, decision-making, prototyping, and user testing into five days. The output is a validated decision — not a prototype that nobody tested.

## Agent Roster

### Sprint Core

| Agent | Role |
| --- | --- |
| Agents Orchestrator | Sprint facilitation and timeboxing |
| UX Researcher | User interviews and test recruitment |
| UI Designer | Screen design and visual direction |
| UX Architect | Flow design and information architecture |
| Sprint Prioritizer | Question framing and decision criteria |

### Prototype & Validate

| Agent | Role |
| --- | --- |
| Rapid Prototyper | High-fidelity prototype build |
| Frontend Developer | Functional prototype where needed |
| Reality Checker | Test validity and evidence review |
| Inclusive Visuals Specialist | Accessible prototype design |
| Analytics Reporter | Test metrics and signal analysis |

### Handoff

| Agent | Role |
| --- | --- |
| Senior Project Manager | Decision record and next-step plan |
| Brand Guardian | Brand alignment review |
| Executive Summary Generator | Stakeholder readout |

## Day-by-Day Execution

### Day 1: Understand

```text
Morning:
├── Sprint Prioritizer → Sprint question and decision criteria
├── UX Researcher → Expert interviews and user context
├── Analytics Reporter → Existing data and funnel baseline
└── Agents Orchestrator → Map the problem space

Afternoon:
├── UX Researcher → Recruitment for Day 5 testing
├── UX Architect → Current-state journey map
├── Sprint Prioritizer → Target user and moment
└── Quality Gate: Sprint question locked
```

### Day 2: Sketch

```text
Morning:
├── UX Researcher → Lightning demos of adjacent solutions
├── UI Designer → Inspiration and pattern review
├── UX Architect → Solution principles
└── Agents Orchestrator → Four-step sketch briefing

Afternoon:
├── UI Designer → Independent solution sketches
├── UX Architect → Flow sketches
├── Inclusive Visuals Specialist → Accessibility considerations
└── Quality Gate: Sketches ready for critique
```

### Day 3: Decide

```text
Morning:
├── Sprint Prioritizer → Critique and dot-vote
├── UX Researcher → User-impact assessment
├── Reality Checker → Feasibility and testability check
└── Agents Orchestrator → Decision on prototype scope

Afternoon:
├── UX Architect → Storyboard the test flow
├── UI Designer → Key screen direction
├── Rapid Prototyper → Prototype plan
└── Quality Gate: Prototype scope and test script approved
```

### Day 4: Prototype

```text
├── Rapid Prototyper → High-fidelity prototype
├── Frontend Developer → Functional interactions where needed
├── UI Designer → Visual polish and consistency
├── Inclusive Visuals Specialist → Contrast and accessibility pass
├── UX Researcher → Test script and consent
├── Reality Checker → Prototype readiness check
└── Quality Gate: Prototype ready for testing
```

### Day 5: Test

```text
Morning:
├── UX Researcher → Five user test sessions
├── Reality Checker → Observe and validate findings
├── Analytics Reporter → Capture task success and friction
├── UI Designer → Note visual issues
└── Agents Orchestrator → Synthesize observations

Afternoon:
├── Reality Checker → Evidence verdict
├── Sprint Prioritizer → Decision recommendation
├── Senior Project Manager → Decision record and next steps
├── Brand Guardian → Brand alignment review
├── Executive Summary Generator → Stakeholder readout
└── Quality Gate: Decision documented with evidence
```

## Key Decisions

| Decision Point | When | Who Decides |
| --- | --- | --- |
| Sprint question | Day 1 | Sprint Prioritizer + Agents Orchestrator |
| Prototype scope | Day 3 | Agents Orchestrator + Reality Checker |
| Test validity | Day 5 | Reality Checker |
| Build / iterate / stop recommendation | Day 5 | Sprint Prioritizer + Senior Project Manager |

## Success Criteria

| Metric | Target |
| --- | --- |
| User test sessions completed | ≥ 5 |
| Prototype tests the sprint question | Confirmed by Reality Checker |
| Decision documented with evidence | Yes |
| Next-step owner and date assigned | Yes |
| Accessibility pass on prototype | Completed |

## Common Pitfalls & Mitigations

| Pitfall | Mitigation |
| --- | --- |
| Prototype is a demo, not a test | Reality Checker validates testability on Day 3 |
| Testing too few users | UX Researcher recruits from Day 1 |
| Decision deferred after the sprint | Senior Project Manager records decision on Day 5 |
| Visual polish hides usability issues | Frontend Developer builds functional interactions, not just screens |
| Accessibility skipped under time pressure | Inclusive Visuals Specialist runs a Day 4 pass |
