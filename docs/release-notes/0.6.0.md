# Agency Agents 0.6.0

## Highlights

- **Opt-in automatic installs.** The "Install updates automatically" toggle in Settings → Updates now does what it says. Turn it on and Agency Agents downloads, verifies, and installs approved updates in the background; you are only asked before the app relaunches. It is off by default, and the first enablement goes through an explicit consent dialog.
- **Offline Mode stays a hard gate.** The check runs before the toggle is even consulted, and a corrupt settings file fails closed. Turning Offline Mode on pauses background installs immediately.
- **Cancel is honest.** Canceling lands after signature verification and before the bundle swap, so a cancel changes nothing on disk and the update stays available to install later.

## Changes

- Feat: scheduler-owned auto-install. The Rust scheduler drives the flow, so an install survives navigation in the renderer. The first check runs ~60s after launch (with clock-derived jitter), then every 24h while the app is running; failures back off 1h → 6h → 24h, and an inactive app polls every 5 minutes.
- Feat: `download` (which verifies the signature) is split from `install` (the bundle swap), which is what makes the cancel checkpoint above possible.
- Feat: one atomic install slot shared by the automatic and manual paths. Starting a manual install while a background install runs reports `install_in_progress` instead of interleaving two writes.
- Feat: every auto-install exit after the `started` phase emits a terminal phase, and a relaunch is always user-initiated.
- Feat: background progress with a Cancel button in Settings, a status pill in the title bar, and a new `Updated` action in the Activity Journal.
- Fix: six pre-existing backend test failures. A single-file render now hashes the file bytes directly, so reconcile stops classifying every single-file install as `Modified`; `antigravity-md` is registered as an implemented format; renderer tests use the current tool ids (`piAgent`, `ohMyPi`) and the `.pi` project destination.
- Fix: corrected the stale `autoInstallHint` string in eleven locales, which still said the feature was "available once the update channel is live".

## Notes

- **No migration required.** The new setting defaults to `false` and deserializes as such for existing configs.
- **Only scheduler-discovered updates auto-install.** Pressing "Check now" never starts an install; that stays a manual decision.
- **Correction to the v0.5.1 notes.** v0.5.1 listed `antigravity-md` support as shipped, but the format registration actually landed in this release, alongside the renderer test corrections. Both are included here.
- **Known limitations.** The scheduler loop body and the plugin download path sit behind `cfg(not(test))` and are not covered by the unit suite; they are reasoned about and reviewed, not exercised. A manual smoke test on a signed build is still outstanding.
- The eleven translated hint strings were corrected by a non-native speaker and would benefit from a native pass.
- macOS DMGs and `latest.json` are uploaded manually via `scripts/release.sh`; Linux and Windows bundles are produced by the release workflow.
- No breaking changes.
