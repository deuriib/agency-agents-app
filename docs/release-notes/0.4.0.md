# Agency Agents 0.4.0

## Highlights

- In-app update checks now read the latest published GitHub Release instead of
  the legacy `agencyagents.app/updater.json` endpoint. The signed `latest.json`
  attached to that release remains the install artifact.
- Releases without an in-app manifest are announced as "View release"
  (manual download) instead of failing silently.
- Release automation: tag + draft release + Linux/Windows artifact upload via
  `release.yml`. macOS assets are uploaded manually (Keychain signing).
- Version bumps now go through PRs via `scripts/bump-version.mjs`.

## Changes

- Check: `GET /repos/deuriib/agency-agents-app/releases/latest`, compare `tag_name`
  with the running `CARGO_PKG_VERSION`.
- `UpdateCheckOutcome::Available` gains `releaseUrl` and `installable`.
- Legacy `agencyagents.app/updater.json` kept as a one-cycle fallback.
- `scripts/bump-version.mjs` bumps all five version manifests in lockstep.

## Notes

- The release stays a draft until macOS DMGs + `latest.json` are uploaded.
