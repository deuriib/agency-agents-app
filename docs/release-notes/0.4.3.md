# Agency Agents 0.4.3

## Highlights

- Native multi-file renderers land for Kimi, OpenClaw, and Mistral Vibe: these tools move from "recognized-only" to first-class installable targets (per-agent `agent.yaml` + `system.md`, `SOUL.md`/`AGENTS.md`/`IDENTITY.md`, and `.toml` + prompt `.md` respectively).
- Install ledger gains multi-file support (`dests`, per-file hashes) with backward-compatible migration of older ledgers.

## Changes

- Feat: `render_files()` API in the Rust backend; single-file tools delegate and wrap, multi-file tools emit all files.
- Feat: `write_agent_files_to` writes every rendered file, computes a composite hash, and records per-file hashes + all destinations.
- Feat: UI enables Kimi, OpenClaw, and Vibe installability (Aider/Windsurf roster tools remain gated pending aggregate install flow).
- Docs: Enterprise Feature Development runbook execution artifacts (Phases 1–4), UX research, system architecture, RICE backlog, compliance scan.

## Notes

- Multi-file reconcile and removal, roster aggregation for Aider/Windsurf, and upstream parity tests are tracked for a follow-up release.
- macOS DMGs and `latest.json` are uploaded manually via `scripts/release.sh`.
- No breaking changes; older ledgers migrate automatically.
